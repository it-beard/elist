# inbox/terror — файл пераліку КДБ

Сюды кладуць `Перечень.xlsx` з Telegram-канала КДБ (пост «Перечень организаций и физических лиц, причастных к террористической деятельности от ДД.ММ.ГГГГ»): праз `git push` або кнопку «Add file → Upload files» на GitHub.

На push у `main` джоб `inbox` (`.github/workflows/update-and-deploy.yml`) разбірае файлы па чарзе (па назве), даўносіць новых людзей у `data/terror.json`, выдаляе файлы з гэтай тэчкі, дасылае дайджэст у Telegram, камітуе і публікуе сайт.

Дату версіі пераліку (з паста ў канале) пазначайце ў назве файла: `2026-09-11.xlsx` або `Перечень-11.09.2026.xlsx`. Без даты возьмецца дата захавання файла з яго ўласцівасцяў (звычайна на дзень-два раней за пост).

Калі разбор не ўдаўся (змяніўся фармат, спрацавала засцярога), файл застаецца тут, а адмін атрымлівае алерт.

Ёсць і шлях без гэтай тэчкі: пры кожным абнаўленні CI глядзіць публічнае прэв’ю канала КДБ і пра новую версію піша адміну ў Telegram са спасылкай на пост; дастаткова пераслаць гэты пост боту — файл імпартуецца пры наступным абнаўленні.
